# Školní bufet Online objednávky
Rezervační systém pro vytváření online objednávek pro školní bufet.

## Features
- Přehledné UI/UX
- Živý KDS (Kitchen Display System)
- Integrace platební brány ThePay
- Registrace uživatelů
- Rozdělení položek do kategorií
- Jednoduchá instalace a správa
## Instalace
### Debian, Ubuntu, CentOS, Fedora
Doporučená metoda instalace je přes interaktivní instalační skript.

Ten pro vás také nainstaluje potřebné závislosti, nechá vás provést základní konfiguraci, nastaví zálohování podle vašich potřeb, a nainstaluje monitoring pomocí aplikace Uptime Kuma.

Pro instalaci aplikace je potřeba být přihlášen jako uživatel 'root' či mít neomezená práva 'sudo'

Stáhněte ho a spusťte následujícími příkazy a postupujte podle pokynů na obrazovce
```
wget https://vlastas.cc/buffet-conf/installer.sh
chmod u+x installer.sh
./installer.sh
```
